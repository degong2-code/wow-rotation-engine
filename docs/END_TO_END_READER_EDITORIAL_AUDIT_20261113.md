## 3. 고양 V3.11: 좋은 내용과 우선 고칠 독자 경험 분리

### 보존할 실제 유용 콘텐츠

- 가장 앞의 **한눈에 보는 딜사이클**에는 영웅 특성별 ST/AoE 운용·오프너 및 M=소용돌이치는 무기 중첩/임계값이 들어 있다.
- **4개 실제 우선순위(폭풍인도자 ST·AoE, 토템술사 ST·AoE)**는 `순위/행동/조건` 형식을 사용하고, 최신 원문에서 검토된 9/10/12/12행과 연결된다.
- 실제 원문이 다른 시전 타이밍을 요구하는 **12개 물약 선택별 오프너**를 상호 배타적 접기/펼치기로 정리했으며, 기본 선택과 예외를 구분한다.
- 자원 생성/소비·영웅 특성 차이·토림의 기원·쿨기 연계·시즌 세트의 이유/주의 등 **실전 판단에 필요한 심화 원리**가 존재한다.

### 독자 본문에서 분리해야 할 품질 결함

**E01 — 개발용 상태 보고가 플레이어 본문에 침투.** V3.11 6.7절 **'추가 수집 상태'**에는 V3.1→V3.2 패치 자료 충돌, 검색 색인과 직접 열람 텍스트의 차이, Gate A 판정, 실사이트 UI 감사 미실시 범위 등을 상세히 썼다. 이는 플레이어에게 어떤 기술을 언제 사용하라는 내용이 아니라 **개발 감사 이력**이다. 사용자에게 거짓 완성도를 주장하지 않도록 교본에 짧은 출처/검토 범위 표시는 남기되, 버전 복구·취득 방식의 장문 설명은 **GitHub 비공개/공개 가능한 감사 문서의 메타데이터**에만 둔다. 더구나 이후 실제 HTTPS로 사용자 저장본과 동일 원문 SHA를 검증했으므로 과거의 수집 상태 설명을 최신 사실로 단정해 표시하면 혼란이 커진다.

**E02 — 검증용 상태 사례가 '심화 운용법'처럼 보임.** 6.8절에 **15개 상태→다음 행동 점검 표**와 13개 내부 일치/2개 판단 보류 상태를 공개했다. 'ST-S01' 같은 QA ID, 테스트 전제, 내부 PASS/REVIEW는 독자가 게임 중 빠르게 찾을 요약/조건표와 다른 목적의 자료다. **이 표 전체는 개발 검증 기록으로 유지**하고, 플레이어 교본에는 독자의 행동을 실제로 바꾸는 **검증된 예외·수치·원리만** 자연스러운 설명으로 반영한다. 미확인 2개의 조건은 임의 답을 만들지 않으며 필요할 때만 **짧은 '검증 대기' 주의**로 표기한다.

**E03 — 편집 결과와 사실 검증 상태가 뒤섞일 가능성.** 예컨대 V3.11 4장의 '출처·판정 주의'와 6.6절 과거/신규 패치 이력은 핵심적인 구버전 혼용 예방 목적은 있으나, 독자에게 필요한 것은 **현재 적용 패치와 '과거 조건을 적용하지 않는다'는 결론**이다. 과거 수정 프로세스·로그·누락 수치까지 설명할 필요는 없다. 다만 실제 게임 판단을 바꾸는 중요한 옛 규칙/신규 규칙 차이는 **짧고 명시적인 주의사항**으로 보존한다.

**E04 — 미검증 사항을 숨기거나 과장하지 않기.** V3.11의 미해결 2문제는 (a) 토템술사 5–9중첩 조기 소비가 직전 우선순위와 충돌하는 특정 상태, (b) 폭풍인도자 AoE 9중첩+폭풍 발동·생성기 불가의 다음 기술이다. 정확한 다음 GCD는 이 근거만으로 확정 불가. 둘 모두 전체 정상 우선순위를 붕괴시키는 것으로 단정하거나 거짓 해답을 보충하지 않고 **관련 우선순위 행과 인접한 최소 검토 주의**로 유지한다. 개발자용 상세 반례 ID·표는 교본에서 분리한다.

## 4. 실제 수정 사양 — 새 엔진 없이 하나의 HTML 편집으로 처리

1. **남길 부분:** 빠른 참고, 4개 순위표(조건 포함), 12개 실제 오프너, 자원/쿨기 메커니즘, 실전형 예외, 정확한 기술 링크/아이콘, 기존 V11 7전문화 원본.
2. **본문에서 옮길 부분:** 6.7절의 과거 개발/출처 취득 상태, 6.8절의 15개 내부 QA 사례·점검 ID, 4장/6.6절의 개발사고 경위 장문 → GitHub 기존 Q0/Q1/원문 취득 감사 문서 참조.
3. **본문에 남길 검토 주의:** 적용 패치·기준 출처·실제로 미검증인 특정 두 행동 선택을 사용 조건 바로 근처에 **짧게** 표시. 실전 예외를 삭제하거나 근거 없이 확정하지 않는다.
4. **검증:** 수정 전/후 해당 전문화의 ST/AoE 우선순위 43행과 유효 오프너 12개 **조건·순서 동등성**, 독자용 첫 화면 내용, 7개 기존 V11 `manual-view` 바이트 동일, 데스크톱/모바일 버튼·툴팁 작동. Q0/Q1과 Q4는 별도 판정.
5. **실행 차단 사유:** 현재 V3.11은 개인 Library에서 **색인 텍스트는 읽혔지만 raw HTML 바이트 재료 확보가 허용되지 않았다.** 원본 바이트 기반 안전 편집은 수행하지 않았고 교본 V3.12 또는 수정 파일이 생성된 것처럼 보고하지 않는다. 승인·정본 변경도 없음.

## 5. 모든 전문화로 전이할 수 있는 최소 원칙

**독자 교본에는 전투 판단과 이해에 유용한 정보를, 개발 기록에는 원문 확보·실험·QA ID·버전 비교·검증 범위를 둔다.** 두 층의 출처·검토 상태는 모순되지 않아야 하지만 **개발 기록 전체를 교본에 싣는 것은 품질이 아니다.**

이 원칙은 V11 정상군에서 확인한 차이에 기반한 **편집 역할 분리 정책**이며, 특정 전문화에 동일 장 수/표 수/글자 수를 강제하지 않는다. 독자용 검증 상태 경고는 실전 오해 방지에 중요한 경우에만 최소한으로 남긴다.

**다음 작업:** 개인 V3.11 원본 바이트를 접근 가능한 파일 참조로 확보할 수 있을 때 위 한 번의 편집을 실제 교본에 적용하고, 먼저 Q2/Q3 편집 개선 + Q4 원본 보존을 확인한 후 새로운 전문화로 **CREATE/UPDATE 전체 과정 재현**을 시도한다. 그 전에는 새로운 미시 검사기 개발보다 실제 교본 구조·내용 비교를 우선한다.
