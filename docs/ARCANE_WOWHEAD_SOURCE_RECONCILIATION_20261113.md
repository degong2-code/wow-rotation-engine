# 비전 마법사 Q0/Q1 — Wowhead 12.1.5 우선순위·오프너 실제 대조 (2026-11-13)

## 0. 목적과 결과 상태

기존 비전 HTML의 **시각/UI 개선을 보존하며 실제 게임 판단 정확성을 높이는 작업**이다. 신규 검사기·스키마를 만들지 않고, 기준 Wowhead 12.1.5 원문에 따라 **기존 초안의 34행에서 잘못 단순화되거나 중복된 조건과 오프너를 수정**했다. **전체 원문 선택형 UI·개별 ? 팁의 전수 확보를 주장하지 않으며 Q0/Q1 최종 승인은 REVIEW**다.

**기준:** [Wowhead Arcane Mage Rotation](https://www.wowhead.com/guide/classes/mage/arcane/rotation-cooldowns-pve-dps), 검색 색인 **2026-10-16 / 12.1.5**, 저자 Porom. [한국어 Wowhead 페이지](https://www.wowhead.com/ko/guide/classes/mage/arcane/rotation-cooldowns-pve-dps)의 검색 색인은 **2026-10-13 / 12.1.5**. **중요:** 같은 URL을 웹 직접 열람하면 때로 2026-06-19 / 12.0.7 **오래된 판이 반환**된다. 따라서 **직접 열람 12.0.7의 기술 규칙은 12.1.5 우선순위와 섞지 않았다**. 12.1.5 검색 색인 본문의 영웅 2종 우선순위와 확인 가능한 오프너를 사용하며 **원본 raw WHML SHA·동적 선택 UI 전체 확인은 아직 별도**다.

개인 결과 파일: `wow_rotation_v11_arcane_wowhead_1215_reconciled_REVIEW.html`, **977,287B**, SHA256 `54c1d7a19cf5fa1731dc4139adfc0f067da779b913d82bd077578714ce12fc33`. V11 7전문화 비공개 HTML 원본을 공개 GitHub에 업로드하지 않았으며 **결과물도 사용자 채팅 파일로만 제공**. 기존 V11 기준 SHA256 `5d70279c4dd073eccef1f3b13565a8f555cd81c9f0a5b7eda7e3485e410742be`.

**우선순위 구조:** Wowhead의 기준은 **성난태양 10개 통합 순위, 주문술사 9개 통합 순위**, 이 중 일부는 특정 대상 수에서만 적용됨. 2종 영웅×단일/광역 표로 분리한 후 **성난태양 9+10행, 주문술사 8+8행 = 35행**. 분리 후 원문의 행 수와 같아야 한다는 **고정 개수 규칙을 사용하지 않는다**. 주문술사 2명 이상의 첫 오색 화살 발동이 하위 중복 행을 완전히 가리므로 **8행**인 것은 의도적.

**설명/표현:** 기존 V11의 2열 요약·3열 우선순위·기본 판단 이유 상시 표시·선택적 `?` 심화·단계별 오프너라는 **공통 UX 계약 유지**. 원문에 없는 수치·팁을 `?`에 지어내지 않고 필수 조건을 먼저 공개한다. 원문에서 비전 파동은 성난태양 **기본 추천 빌드에 포함되지 않는다**는 조건을 보존.

## 2. Q0–Q4 실제 결과

- **Q0 출처 사실:** 공개 12.1.5 검색 색인의 원문 우선순위 및 오프너와 이번 수정의 조건·순위 대조 **부분 통과**. 실시간 원본 동적 탭, 관련 툴팁 전수, 비전 파동 SSOrb 선택 참조 및 주문 ID 7개 미확인은 **REVIEW**. 직접 URL 본문이 12.0.7로 돌아오는 버전 충돌을 과장 없이 표시.
- **Q1 판단:** 정량 임계값 0↔3, 5명 조건, 12중첩, 주문술사 광역 중복 제거, 오프너 시점·충전물 예외를 구체적으로 수정. **실제 전투 전체 상태/최적화 검증은 미완료**.
- **Q2/Q3 설명/가독성:** 기존 V11식 요약·순위/행동/조건·상시 이유·심화 선택 정보 유지. 미확정 문제를 대형 개발 로그로 노출하지 않고 플레이어에게 필요한 오프너 주의만 간결하게 표기.
- **Q4 기존 본문:** 실제 원본 `wow_rotation_manual_engine_v2.html`(898,297B, 위 SHA)의 **7개 manual-view 바이트를 각각 추출**하여 신규 출력과 비교 **7/7 동일**. 8개 총 전문화와 신규 4개 순위표(9/10/8/8), 7개 오프너 행을 파싱 검증.
- **Q4 Chromium:** 데스크톱 **1365×880**, 모바일 **390×844**, `page.set_content`에서 비전 교본 선택·영웅 전환·표별 조건, 기술 툴팁, 기존 냉기 교본 복귀, `#arcane-rotation` 해시 복원, 문서 전체 가로 넘침 없음, JS page errors 0 **두 뷰포트 PASS**. 로컬 `file://` 직접 열람은 실행 환경 정책으로 제한되므로 사용자 환경 전수 PASS 주장 금지.

## 3. 남은 가장 중요한 실제 교본 문제

1. **기준 원문의 실제 선택형 페이지 완전성:** 12.1.5 본문 검색 색인과 원본 12.1.5 WHML/툴팁/영웅별 동적 오프너의 차이를 확인. 해당 분기 자체가 행동을 바꾸는 경우에만 심화 수정·후속 UI를 확장.
2. **복합 조건 상태 검사:** 예: 성난태양 충전물 1~2와 선행 쿨다운, 5대상/12중첩/준비된 보주 등 동시 상태, 주문술사 2인 이상 오색 화살·보주 충전 상한·20중첩 동시. 같은 원문 조건에서 **최상위 충족 행**이 선택되는지 Q1 검증. 원문 자체 불명확하면 REVIEW.
3. **기존 비전 초안의 심화/근거 독립 검증:** 원문 12.1.5 선택형 특성·쿨기·기술 아이콘 7/12 미확인을 재검토. Q0/Q1 승인 전 신규 교본을 `main` 정본으로 승격 금지.

**범용화 결론:** '원문 통합 우선순위 → 단일/광역 분리'는 단순 표 복제가 아니라 **정량 조건의 논리적 분할·불가능한 행 제거·중복 행 통합**을 수반한다. 콘텐츠 의미 검증이 우선이고, V11 공통 시각 계약은 변경하지 않는다. 이 원칙은 다른 전문화의 전투 모드 표 변환에도 적용 가능하나, 한 전문화의 임계값·행 개수는 강제하지 않는다.
