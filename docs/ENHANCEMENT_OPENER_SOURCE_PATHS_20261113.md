## 1. 근본 원인과 재발 방지 설계

선택 조건을 단일 ID 일치로 간주하면 실제 원문의 부정·결합·상위 선택 표시 조건 때문에 정상 단계가 누락된다. 실제 확인한 WHML 조건식:
- 단일 ID: SB-OP-AOE-Reck
- 부정: !T-OP-ST-Reck
- 부정과 AND: !(T-OP-ST-Reck)&!(T-OP-ST-LL)&!(T-OP-ST-LP)
- 공통 영웅에 OR: SB-Master|T-Master
- 각 이벤트 조건에 상위 영웅/대상 선택 컨테이너가 AND로 적용

공통 해석기는 **원문에서 관찰한 문법**인 ID, !, &, |, 괄호만 지원한다. 미선언 토큰·불완전한 문법·지원하지 않는 기호는 None/REVIEW로 보류하며 임의로 제외하거나 포함하지 않는다. 이 조건식은 **원문 UI의 표시 조건**이며 게임플레이 판단 조건을 자동 도출하는 도구가 아니다.
