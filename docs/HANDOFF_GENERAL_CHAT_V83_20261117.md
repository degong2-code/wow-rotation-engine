## 4. 사용자 확정 집필·UI 원칙

1. **한눈에 보는 딜사이클**에서 단일/광역 지속 딜과 오프너, 핵심 운용, 중요 쿨다운/자원·심화 판단을 실제로 사용할 수 있어야 한다. 조건이 맞는 **다음 기술**을 독자가 고를 수 없으면 실패. 단일/광역을 매번 페이지 상단까지 왕복해 바꾸는 탭은 가독성 단점이 있었다.
2. 원문은 **하나의 패치·빌드·주된 Wowhead 기준**으로 선택. 영웅 특성·대상 수·특성 선택/물약 옵션·접힌 단락/`?` hover·원문 오프너의 실제 분기를 **선택별** 확보; 별개 선택 텍스트가 이어져 보인다고 연속 시전으로 착각하지 않는다. 다른 출처는 교차 대조이지 우선순위 혼합 금지.
3. 먼저 **상태·조건·행동·이유·예외를 추출**하고 표/장 구조를 정한다. 표는 필요에 따라 `순위 / 행동 / 조건(이유)`. 기술명은 **아이콘 + 강조**, 실제 조건은 **괄호·작은 글씨·옅은 색**. 설명은 간결한 **중간 수준 압축**(예: '마무리 기술: 연계 점수 6점 이상에서 사용')을 선호. `사용 가능할 때`, `상위 조건 없음` 등 중복 문구를 제거하되 AND/OR·초·중첩·대상 수·부정 조건은 보존.
4. **지속 딜의 `→`는 우선순위**, **오프너의 `→`는 원문 시전 순서**. 소비재·물약은 **기술 사용 우선순위표에 넣지 않으며**, 실제 원문 오프너에서 사용 시점이 바뀌면 그 시점은 보존. 기술명은 공식 한글, 내부 키/원시 영문 약어/`∧` 등 화면 노출 금지.
5. 영웅 특성이 실제 판단을 바꾸면 핵심·심화·오프너를 **선택형으로 나눠 표시**. 기술·버프·발동 아이콘은 확인된 것만 연결, 미확정 이미지 임의 대체 금지. `?` 툴팁에는 고급 예외·심화 이유를 두고 **일반적인 판단 이유는 본문**에 남긴다.
6. **가상의 '실전 상황별 판단 예시' 독립 장 금지**; 내부 반례 QA는 유지. V11의 UX를 참고하지만 과도한 박스/반복 안내·불필요한 테두리/메타데이터를 늘리지 않는다.
7. **디자인 잠정 기준:** 고통의 **흰색·굵은·밑줄 없는 기술명**, 파괴에 대한 V83 시범은 가독성 유망. **금색/핫핑크/밑줄/문단 간격/전체 서체 통일은 아직 최종 승인 아님**. 사용자가 실제 V83 비교 후 전체 교본 UPDATE 시 의미 역할을 정해야 한다.
8. 일반 ChatGPT 채팅으로 실행하고, 새 교본/중요 UPDATE 후 **개인 Library 파일 저장 + 실제 크기/SHA/전문화·Q4 결과 + GitHub CURRENT_STATE 기록**까지 종료 절차로 삼는다. 개인 파일 저장 누락은 재현성을 떨어뜨리는 실패다.

- **Q3:** 첫 화면·표·모바일·메뉴·아이콘 등 독해/실전 사용성.

- V83의 **검사한 Q4 범위는 PASS**이고 제품 커밋 **CI success**. 그러나 **전체 Gate A·Q0/Q1, 사용자 V83 Q2/Q3 최종 승인, 실제 외부 CDN 아이콘 응답·일반 file:// 기기 동작, 일부 비전 모바일 경계는 REVIEW**. 사용자 UI 칭찬은 게임 내용의 최종 승인과 다르다.
- 그 외 영웅/선택형 숨은 원문·한 전문화의 작은 불명확한 경계 문제는 **실제 다음 기술 결정에 중요하면 좁게 확인**, 근거가 없으면 REVIEW로 종료하고 더 중요한 제품 작업에 복귀한다.

## 6. 새 채팅에서 수행할 다음 작업 1~3개

1. **V83 통합 실물의 사용자 Q3 검토 의견 반영** — 파괴/비전의 배경 연결, 파괴 기술명의 밑줄 제거·hover·focus, 기존 고통과의 표현 일관성을 실제로 확인. **전체 타이포/행간/색 의미를 사용자 승인 없이 무조건 14개에 전파하지 않는다.**

3. **실제 영향 큰 Gate A/Q0/Q1 원문·조건 누락 감사 + 전체 교본 디자인 정규화 시점 판단** — 파괴 경계·비전 Tips 등은 기존 자료와 정상 취득법에서 증명할 수 있을 때만 해당 규칙을 수정. 심화→첫 화면 역방향 조건 누락은 신규/UPDATE마다 확인. 제품 전체 서체·배경·색의 의미 체계는 **V83 사용자 평가 뒤 명시적으로 전체 UPDATE가 필요할 때** 진행.

새 검사기·독립 엔진·특성/물약 한두 개에 매몰되는 작업을 우선하지 않는다. **두 종료 판단 기준**은 (a) 독자가 실제 상태에서 정확한 다음 기술을 고를 수 있는가, (b) 다른 전문화도 V11 이상 품질로 반복 제작되는가.
