# V2 엔진 → PUBLIC GitHub 이관 계획

## 현재 분리 원칙

- **이관 가능:** Python 엔진 코드, 테스트, JSON Schema, 규칙 파서·검증기, 일반화된 템플릿, 문서.
- **검토 후 이관:** V11에서 도출된 스킬별 한국어 설명·딜사이클 규칙 및 유의미한 원문 구조의 파생물.
- **공개 금지(허가 전):** 와우헤드 영어 원문 전문, 그 전체 번역문, 사이트의 대량 수집 데이터, 인증 비밀.
- **임시 저장·배포:** Actions Artifact는 짧은 기간만 유지. PUBLIC Actions artifact에는 비공개 원문을 포함하지 않음.

## 현재까지 완료된 V2 원본의 역할

이전 로컬 V2 패키지에는 7개 전문화·60개 장·177개 우선순위 행·79개 Advanced Tips 후보·10개 예제 조건 계약이 있었습니다. 이 수치는 **이전 로컬 V2 자체 보고 기준**이며, 해당 데이터는 **아직 이 공개 저장소로 이관하지 않았습니다**.

초기 GitHub CI는 합성 데이터만 검증합니다. V11 교본 재생성 SHA-256 일치, 실제 177개 행 검증, 실제 7개 전문화 UI 테스트는 이 저장소에서 아직 실행되지 않습니다.
