기존 고양 V2.1의 Wowhead 평면 추출만으로 누락되거나 결합됐던 규칙을 확인 가능한 범위에서 복구했다. 새 파일은 `wow_rotation_v11_enhancement_v3_expanded_review.html`, **1,057,340 bytes**, SHA256 `287227572290dc90c13b0da220410280b9b7289e22594b97203d278b35a14eae`. 원본 V11의 7개 본문은 삽입 지점 이전 HTML 원시 바이트 동일, 원래 스크립트·푸터 동일. 신규 교본의 실행 우선순위 **4표, 43행(9/10/12/12)** 그대로.

**직접 출처:** [Wowhead 고양 회전 공략](https://www.wowhead.com/guide/classes/shaman/enhancement/rotation-cooldowns-pve-dps), 편집자 wordup. 일반 본문 열람(web 텍스트 뷰)에서는 접힌 Notes 본문과 선택별 오프너의 일부 조건이 누락/평면화된다. 같은 URL의 검색 색인에는 더 풍부한 ST/AoE Notes·오프너·5개 쿨다운의 서술이 나온다. 검색 색인을 실제 UI의 각 선택 상태 조작으로 대체해 **전수 확인했다고 주장하지 않는다**. 인터넷 연결된 실제 Wowhead GUI 직접 조작은 이번 실행에서 가능하지 않았고, 로컬 HTML의 브라우저 조작만 시험했다.

## 실제 파일에 보강한 게임 판단

- **Stormbringer ST/AoE Notes**: 폭풍 발동·소용돌이치는 무기 중첩의 소비, 승천 중 낙뢰/바람의 일격, 폭풍 이후 토림 자동 주문 변경.
- **Totemic ST/AoE Notes**: 파멸의 바람 10초·뜨거운 손, 5중첩 조기 소비 예외, 단일/광역 오프너의 토템 연계 차이.
- **토림의 기원 설정**: 폭풍 1명 적중→번개 화살, 2명 이상→연쇄 번개, 번개를 타고 발동은 설정에 영향 없음. 태고의 폭풍은 이전 타격 대상 수에 따라 갈리지만 **수치 경계 미확인**.
- **쇄도하는 토템 효과**: 휘몰아치는 대지 다음 세계의 분리 +100%, 원시 촉매의 용암 채찍 150% 추가 발동 등 4개 효과의 사용·소비 관계.
- **물약 선택 비교**: Liquid Luster의 단일 -10~-12초 사전 사용 및 두 번째 -10초 원칙, Recklessness의 전투 전 사용/능력치 선택, Light's Potential은 **탭별 정확한 시전 단계 미확인**으로 표기. 모든 물약을 한 오프너에서 순차 사용하라고 지시하지 않음.

모든 수치는 **해당 Wowhead 패치 설명에 대한 편집 상태**이지 게임 내 최신 빌드 전체의 독립 성능 실증이 아니다.

## 2026-11-12 사용자 교정 — 물약별 오프너는 잘못 설정한 수집 과제

앞선 표의 'Potion … **각 물약 × 영웅 × 전투 형태의 실제 동적 단계**'와 일부 문단의 '물약별 오프너'는 **당시의 과도한 요구**였으며 **현재 필수 작업이 아니다**. Liquid Luster / Potion of Recklessness / Light's Potential 등의 이름은 사용자·장비가 선택하는 소모품 **예시**이며, 서로 다른 독립 기술 오프너를 의미하지 않는다. **영웅 특성 × 단일/광역에 따라 핵심 기술의 순서·선시전·첫 버스트 조건을 확인하고, 그 순서에서 물약이 사용되는 위치를 `물약 사용`으로 표시**한다. 효과가 실제 기술 사용 순서를 바꾼다는 원문 근거가 있으면 해당 예외만 조사한다.

기존 자료의 일부 예시 물약에 관한 독특한 효과·사전 사용 수치는 **해당 물약에 대한 선택형 참고**일 수 있을 뿐 모든 물약의 일반 사용 시점이라고 자동 일반화하지 않는다. 오프너 핵심 기술의 선택 상태별 정합성, 실제 관련 `?` 팁의 모든 본문, Notes 등 내용 확보는 여전히 미완료다. 본 문단은 역사적 감사 사실의 수정 설명이며 V3.7 HTML 변경 또는 원문 Gate A 통과를 뜻하지 않는다.
