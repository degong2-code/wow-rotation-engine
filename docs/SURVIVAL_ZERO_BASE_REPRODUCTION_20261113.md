- **영웅별 기본 회전:** 무리의 지도자 ST9/AoE10, 파수꾼 ST10/AoE11 = **40개 편집 규칙/출력 우선순위 행**. 각 원문 후보에 ID/영웅/대상/순위/행동/조건/이유/REVIEW 상태를 동봉 JSON `survival-canonical-1215`로 유지. 단, 이 수는 완전한 원문 원시 행 전수 계수가 아니라 **공개 색인에서 추출해 사용자가 읽을 수 있도록 편집한 판단 행**임.
- **한눈에 보기:** 영웅별 2열 표 2개 × 4상황(단일 지속/광역 지속/단일 오프너/광역 오프너); 핵심 상위 4행은 **같은 40개 기준 데이터**에서 재사용. 고정 콤보라고 읽지 않도록 명시.

## 4. 범용화에서 새로 확인한 근본 위험

**잘못된 기준의 계승은 실패 교본에만 일어나는 것이 아니다. 최신 패치 라벨이 붙은 외부 공략도 현재 패치에서 삭제된 기술을 내포할 수 있다.** 따라서 모든 신규 CREATE/전체 재작성은:

1. 해당 패치의 단일 기준 원문을 확보하고, **원문 업데이트일만 아니라 실제 기술 목록/공식 삭제·변경 사항과 모순되는지** 확인.
2. 원문 직접 캐시와 검색 색인 사이 패치 충돌이 있으면 **버전이 다른 두 페이지의 분기를 결합하지 않음**; 확인 가능한 동적 상태 범위만 책에 넣고 나머지는 REVIEW.
3. 성공한 V11/비전/고양의 **독자용 정보 위계만** 재사용하고 실패 전문화의 게임 내용을 복사하지 않음.
4. 최종 판단은 반드시 **실제 새 HTML의 Q0/Q1/Q2/Q3/Q4** 단독 평가. 코드/테스트 PASS로 게임 규칙 승인 금지.

**다음 우선순위:** 브라우저로 12.1.5 원본 동적 선택형 상태/툴팁을 실제 확보할 수 있을 때 생존 40개 우선순위/4 오프너의 원문 대응 완전성을 보강한다. 새 미세 검사기를 증설하기보다 이미 제작한 **실물 HTML의 게임 내용 REVIEW 원인**부터 해결한다.
