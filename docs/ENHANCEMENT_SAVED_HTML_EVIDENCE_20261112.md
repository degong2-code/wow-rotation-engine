## 공통 수집 정책으로 환류

1. 원본 HTML이 확보되면 **스크립트 내부 내장 마크업·원시 조건 식**까지 추출한다. 빈 렌더링 템플릿만 보고 설명 본문 누락으로 판단하지 않는다.
2. 모든 `display-option`을 기계적으로 ‘게임플레이 분기’로 취급하지 않고, 해당 선택의 `display-options` 조건이 **행동·사용 시점·선시전 여부**를 실제로 바꾸는지를 확인한다. 물약은 **고정 분기 또는 무조건 예시** 어느 쪽으로도 하드코딩하지 않는다.
3. 같은 페이지에서 영웅·대상 유형·물약 **상위 상태가 다르면** 나타나는 하위 옵션도 상태별로 수집한다. 서로 배타적인 선택을 1개의 연속 기술 목록으로 합치지 않는다.
4. `?`는 **정의 전체/참조 수/미정의/미사용**을 구별한다. 실제 DOM 위치·호버 구현이 다른 경우에도 WHML 본문 자체의 확보와 게임 의미를 별도 판단한다.
5. 원문 **완전성**과 **게임 최적화의 정확성**은 독립 게이트다. 사용자의 최신 페이지 저장·WHML의 모든 명명 참조 확인으로 **기존의 최신 원문 HTML 취득 병목은 상당 부분 해결**됐지만, 12개 분기의 독립 실시간 실행/실전 최적화 정확성까지 입증한 것은 아니다.
