## 0. 배경, 목적, 개인정보/정본 경계

**사용자 최신 피드백:** 고양 한 전문화의 카드·표를 바꾸는 것이 최종 목표가 아니라, **전문화가 달라져도 V11 수준 이상의 읽기 경험을 일관되게 재현하는 범용 제작 설계**가 우선이다. 내용 Q0/Q1을 조건 우선으로 개선하는 작업은 계속하되, 디자인 Q3을 소홀히 하는 과거 CREATE 실수를 반복하지 않는다.

**실제 작업:** 개인 V11 원본 7개 `manual-view`를 그대로 보존하면서, 이미 GitHub에 보관한 **비전 마법사 기존 12.1.5 CREATE 초안**(게임플레이 미승인)을 8번째 교본으로 추가하여 **V11 시각 문법 실물 HTML** 생성. 별도 유효/미확정 내용을 섞지 않고 초안 상태를 유지했다. 개인 HTML 및 사용자 화면 캡처는 공개 GitHub에 업로드하지 않았다.

**개인 결과 파일:** `wow_rotation_v11_arcane_visual_contract_REVIEW.html`, 크기 **971,400바이트**, SHA256 `7de144d6eb8e6a2e93cd72e8618f43677cd2f89bb8caa7326aaf45ed760ff711`. 이 파일은 사용자 채팅 전달 전용이다. 기준 V11 원본 SHA256 `5d70279c4dd073eccef1f3b13565a8f555cd81c9f0a5b7eda7e3485e410742be`. 기존 V11 접이식 탐색 메뉴 검토본을 베이스로 사용했으며 **7개 본문 블록 7/7 바이트 동일**.

## 1. 서로 다른 V11 정상군의 실제 독해 문법

| 서로 다른 구조의 V11 전문화 | 원본 `한눈에 보기` 데이터 구성 | 관찰된 공통점 |

## 2. 새로운 비전 CREATE에 적용한 표현 설계

- 신규 `guide-arcane`에 **영웅별 요약 2개, 각 4행, 2열**. 행 역할은 단일·광역·조건부 오프너·주요 예외. 첫 화면에서 선택한 영웅의 표만 보인다. 내용은 해당 영웅의 기존 저장소 초안에서 가져왔다.
- 상세 **4개 우선순위 표·34행**, `순위/행동/조건` 열과 `?` 판단 이유를 분리. 조건을 텍스트 길이 때문에 삭제하지 않는다.
- **오프너는 단계 목록**으로 표시하며 번뜩임/충전물/투사체 이동의 조건을 명시하고, 우선순위와 고정 시퀀스 혼동 방지.
- V11 기존 `overview-table`, `table-scroll`, `priority`, `steps compact`, `glossary-list`, `chapter-heading`, `spell tip-trigger`, `aside` 재사용. 기존 사이드바 **직업/전문화 2단 접기** 유지.
- 새 가이드의 추가 CSS는 `.manual-view.v11-visual-contract` **범용 범위**로 묶고, 영웅 전환은 `[data-select-visual-hero]` + `.variant[data-hero]` + `hidden`의 **전문화 무관한 방식**으로 처리. 전문화별 고유 표시 조건/비율을 새 공통 규칙으로 강제하지 않음.
- **반례:** 기존 고양 V3.13 신규 부분은 기존 요약표가 아닌 `eh-hero` 독립 블록 2개와 긴 오프너 문장이 들어 있었고, 실제 V11 표와 행간 비교성이 약해진 화면을 사용자가 지적했다. 이번 작업은 그 파일을 덮어쓴 것이 아니다.
