# 보안·공개 범위

- 저장소는 **PUBLIC**입니다. 커밋은 삭제해도 Git 이력에 남을 수 있습니다.
- OpenAI/Blizzard/GitHub 토큰, 환경 변수 파일, 비공개 계정 정보 업로드 금지.
- 외부 원문 자동 수집은 이용 약관 및 접근 정책 확인 후 허용된 경로로만 구현합니다.
- 와우헤드의 원문/대량 번역 콘텐츠를 테스트용이라는 이유로 PUBLIC에 포함하지 않습니다.
- LLM 출력은 신뢰되지 않은 입력으로 취급하고, 자동 게시 전 스키마·근거·주문 ID·사람 승인 여부를 검증합니다.
- Actions 워크플로에는 쓰기 권한이 필요하지 않습니다 (\`contents: read\`).
