독립 사례로 **고양 주술사(Enhancement Shaman)** 선택. 기준 공략 [Wowhead Enhancement Shaman Rotation](https://www.wowhead.com/guide/classes/shaman/enhancement/rotation-cooldowns-pve-dps), wordup, **2026-10-13 / 12.1.5**, Stormbringer/Totemic ST/AoE. 개인 기준 내용은 기존 검토 HTML `wow_rotation_v11_enhancement_reader_v313_REVIEW.html`; **이 문서는 개인 V3.13 HTML의 모든 게임 조건이 원문과 독립 검증되었다고 주장하지 않는다**. 공개 인덱스에서는 4개 우선순위의 **기술명과 순서를 43/43 행 확인**, 세부 조건 텍스트/숨김 `?`/물약 상세 12경로의 원문 지문 전체 대조는 별도 REVIEW.

새 표현이 V11과 동일한 표 역할을 사용한다는 점과 **실제로 독자에게 더 좋은지**는 별개다. 동일 Chromium 뷰포트에서 이전 고양 V3.13 vs 새 결과를 측정했다.

| 항목 | 기존 V3.13 PC / 모바일 | 신규 V11형 PC / 모바일 |
|---|---:|---:|
| 한눈에 보기 섹션 높이 | 844 / 1,275px | 938 / 1,503px |
| 첫 우선순위표 높이 | 474 / 477px | 631 / 1,244px |

새 표는 **3열 V11 반응형 전개 + 공개 판단 이유**를 보여주므로 세로 길이가 늘어났다. 이를 내용 삭제로 해결하면 조건 보존을 다시 위반한다. 따라서 **전문적으로 더 읽기 쉬운지 Q3 사용자 확인은 아직 REVIEW**. 미관 비교에서 낮아진 탐색비용과 늘어난 스크롤의 교환관계를 숨기지 않는다. 더 간결한 표현은 사용자 피드백 이후 기존 역할을 유지하며 조정한다.

## 구조적으로 이번에 확인된 것과 남은 것

**독립성 의미:** 비전은 Wowhead 영웅별 **통합 우선순위 19개 → ST/AoE 36개 출력 행**을 만드는 사례였다. 고양은 Wowhead가 이미 영웅×ST/AoE를 **4개 표(9/10/12/12)**로 제공하며, 기존 V3.13 검토본을 바탕으로 **하나의 내부 43개 정본→동일 분기·요약 표의 일관 출력**을 시험한 사례다. **서로 다른 원문 구조 모두 같은 조건-보존/출력 역할 계약을 사용할 수 있다는 긍정 증거**지만, 고양에 대해서는 **원시 Wowhead HTML에서 43개 규칙을 새로 독립 추출한 게 아니므로 전체 source→HTML 정밀 제작 재현성이 확정됐다고 과장하지 않는다.**

**재사용 자산:** 기존 `engine/gameplay_decision_qa.py`의 `project_priority_view`/`audit_priority_view`는 조건형 원문을 정본으로 보존하는 기반이며, V11 `overview-table`/`priority`/`spell`/`tip-trigger`/접기 메뉴는 표현 자산. 이번 비공개 편집 작업의 DOM 처리 방식은 특정 고양 UI를 **V11 공통 표현으로 재배치한 시범**이고, GitHub의 Arcane CREATE 코드가 다른 전문화를 자동 CREATE하는 범용화까지 완료했다는 증거는 아니다.

**다음 실제 제품 기준:** 다음 CREATE/UPDATE에서 기존 정본 소스의 **실제 선택형 툴팁·원문 범위를 먼저 검증**하고, 최종 사용자 단일 HTML에서 **조건의 원문 추출과 UI 의미 보존을 모두 확인**한다. 추가 대형 스키마/특성별 검사기 자체를 성과로 보지 않는다. 개인 원문/HTML 또는 대량 Wowhead 인용은 GitHub에 게시하지 않는다.
