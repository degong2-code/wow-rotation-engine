- **정확히 1개 우선순위 조건 셀**(폭풍인도자 광역 10순위)을 `M≥5 / 상위 행동 불가 시 최하위 소비 / 폭풍 발동 시 M10 폭풍 우선 목표 / 승천·파멸 비활성`으로 보강. `폭풍` 발동 시의 10중첩 **목표**이지 모든 상태에서 무조건 대기 또는 항상 같은 버튼을 누른다고 단정하지 않는다.
