# V11 구조화 규칙 데이터 공개 범위

이 저장소의 `content/public/`은 사용자가 검토·편집한 V11 교본에서 추출한 **구조화 데이터 색인**입니다. V11의 전체 HTML, 영문 와우헤드 공략 원문 및 대량 번역문은 포함하지 않습니다.

| 데이터 | 등록 범위 | 검증 상태 |
|---|---|---|
| 전문화/영웅 특성 | 7개 전문화, 9개 영웅 특성 옵션 | V11과 연결만 검증 |
| 우선순위 | 23개 표, 177행의 순번·주문 ID·불완전한 조건 태그 | 외부 원문·최신 패치 미검증 |
| Advanced Tips | 79개 항목의 주제·태그·근거 위치/해시 | 전문 내용 비공개, 의미 검증 대기 |
| 기술명 | 176개 주문 ID, 178개 이름 레코드 | **V11에서 상속**, 공식 한국어 DB 미검증 |
| 미해결 | 13개 복합/설명형 행동의 주문 ID | 임의 결정 금지 |

## 중요한 제한

- `review: pending`, `external_source_verified: false`, `automatic_publish_allowed: false` 상태를 강제로 유지합니다.
- 조건 `semantic_tags`는 **의미 분석을 위한 분류**이지 우선순위 실행 조건식이 아닙니다. `machine_predicates`도 소수 문장의 숫자 부분만 추출한 것으로 충분 조건이 아닙니다.
- `v11_fragment_sha256`는 이관 당시 V11 원문 일부의 해시 식별자입니다. 원문 전체가 공개 저장소에 없으므로 이 해시는 **GitHub 단독으로 내용 대조 불가**합니다.
- 출처 URL은 링크 안내이며, 외부 사이트 전체 원문에 대한 재배포 허가가 아닙니다.
- 초기 생성된 HTML 색인은 데이터 구조를 보여 주는 **검토용 뷰어**로, 추천 딜사이클 가이드는 아닙니다.
- 사용자의 데이터 공개 승인은 확인됐지만 원문 제3자 저작권·이용약관까지 대신 허락하는 것은 아니므로 공략 본문을 대량 게시하지 않았습니다.

## GitHub Actions 검증

```
python -m engine.public_data validate
python -m engine.public_data build --output dist/public-index.html
python -m unittest discover -s tests -p 'test_*.py' -v
```

CI의 검증은 **스키마·숫자·연결·검토 보류 상태**에 대한 것입니다. 실제 게임의 최적화나 공식 한국어 스킬명 정확도를 보증하지 않습니다.

## 이후 작업

- 현재 데이터의 의미 검증을 위해 원문 버전별 변경·특성·스킬 매핑을 확인합니다.
- 와우헤드 자료 접근은 이용 조건을 준수하는 입력 방식으로만 구현합니다.
- 모든 조건을 검증한 뒤 승인된 규칙만 사용자용 교본에 반영합니다.
