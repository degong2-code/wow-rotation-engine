# 조화 드루이드 V11 신규 CREATE — 네 번째 전문화 범용 제작 사례 (2026-11-13)

## 제품 목표와 차별점

기존 비전·고양·생존 리뷰 HTML의 본문을 내용 입력으로 재사용하지 않고, **조화 드루이드 원문으로 상태·조건·행동·이유를 새로 집필**한 다음, PR #23의 **동일 공통 HTML 조립기**로 V11 기존 7개 전문화와 결합했다. 신규 영웅 특성·기술·표는 독립 편집하고, 기준 V11 7개 전문화는 원시 subtree를 수정하지 않았다. 이 작업은 기존 제품 재포장의 반복이 아니라 **새 전문화 콘텐츠 집필 → 공통 조립 → 실제 HTML 검증** 사례다.

## 버전·원문 정합성 (중요)

- 기본 편집 원문: [Wowhead Balance Druid Rotation Guide](https://www.wowhead.com/guide/classes/druid/balance/rotation-cooldowns-pve-dps). **검색 색인 12.1.5 / 2026-10-13**에서는 계절 2 조화 원리, 숲의 수호자·엘룬의 대행자 단일/광역 판단, 주요 쿨다운과 자원 조건을 확인.
- **같은 URL 직접 열람**에서는 **12.0.7 / 2026-08-09** 페이지가 반환되므로 최신 검색 색인과 **혼합하지 않는다**. 12.0.7 한국어 페이지는 기술명 식별만 참고했고, 오래된 우선순위·대상 수 임계값을 12.1.5 콘텐츠로 복사하지 않았다.
- [블리자드 공식 한국어 영웅 특성 명칭](https://worldofwarcraft.blizzard.com/ko-kr/news/24025828)을 기준으로 **숲의 수호자 / 엘룬의 대행자**를 사용. '엘룬의 선택'으로 영웅 이름을 오인하지 않는다(화신 기술명 '화신: 엘룬의 선택'과 구분).
- 주요 누락: **Hero Talent 마스터 스위치와 Incarnation/Convoke/Mythic+ 선택별 실제 오프너 타임라인**, 페이지 동적 툴팁 전체 본문, 검색 색인에 생략된 선택별 행. 이를 사실처럼 채우지 않고 원문 타임라인 **REVIEW**. 12.1.5 직접 원시 WHML 상태를 확보하지 못해 Gate A 미통과 / Q0,Q1 REVIEW.

## 범용화 성과 / 남은 핵심 작업

- 이번에는 이전 생성기를 새 전문화 전용으로 복사하지 않고, 4번째 실제 신규 전문화가 **동일 공통 조립기**로 최종 HTML 출력에 들어감을 확인했다. 전문화 ID/영웅 특성/스킬 이름/표 내용이 조립기 코드에 전혀 추가되지 않았다.
- **원문 자동 수집→동적 선택 완전 추출→게임 판단 자동 집필**까지 전자동 구현했다고 주장하지 않는다. 현재 가장 중요한 지점은 원문의 직접 12.1.5 동적 타임라인을 확보해 오프너·각 영웅의 게임 우선순위 Q0/Q1 REVIEW를 해소하는 것이다.
- 기능 개발보다 실제 12.1.5 원문을 확보하여 본 교본의 조건 정합성과 사용성을 고도화하는 것이 다음 우선 과제다.
