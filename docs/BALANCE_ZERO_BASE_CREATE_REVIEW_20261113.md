# 조화 드루이드 V11 신규 CREATE — 네 번째 전문화 범용 제작 사례 (2026-11-13)

## 제품 목표와 차별점

기존 비전·고양·생존 리뷰 HTML의 본문을 내용 입력으로 재사용하지 않고, **조화 드루이드 원문으로 상태·조건·행동·이유를 새로 집필**한 다음, PR #23의 **동일 공통 HTML 조립기**로 V11 기존 7개 전문화와 결합했다. 신규 영웅 특성·기술·표는 독립 편집하고, 기준 V11 7개 전문화는 원시 subtree를 수정하지 않았다. 이 작업은 기존 제품 재포장의 반복이 아니라 **새 전문화 콘텐츠 집필 → 공통 조립 → 실제 HTML 검증** 사례다.

## 범용화 성과 / 남은 핵심 작업

- 이번에는 이전 생성기를 새 전문화 전용으로 복사하지 않고, 4번째 실제 신규 전문화가 **동일 공통 조립기**로 최종 HTML 출력에 들어감을 확인했다. 전문화 ID/영웅 특성/스킬 이름/표 내용이 조립기 코드에 전혀 추가되지 않았다.
- **원문 자동 수집→동적 선택 완전 추출→게임 판단 자동 집필**까지 전자동 구현했다고 주장하지 않는다. 현재 가장 중요한 지점은 원문의 직접 12.1.5 동적 타임라인을 확보해 오프너·각 영웅의 게임 우선순위 Q0/Q1 REVIEW를 해소하는 것이다.
- 기능 개발보다 실제 12.1.5 원문을 확보하여 본 교본의 조건 정합성과 사용성을 고도화하는 것이 다음 우선 과제다.

## 2026-11-14 교정 V2 — 화신/일월식 배타 상태 혼합 방지

- **실제 사용자 행동 오류:** 첫 HTML의 숲의 수호자 광역 첫 화면 오프너가 '자연의 군대 → 화신 → 대상 수에 맞는 일반 일월식'을 **연속 시전**하는 순서로 읽혔다. 같은 12.1.5 [Wowhead 원문](https://www.wowhead.com/guide/classes/druid/balance/rotation-cooldowns-pve-dps)의 쿨다운 심화에 따르면 **천체의 정렬/화신 중 일반 일월식은 시전할 수 없으며**, 큰 쿨다운을 일반 일월식 도중 쓰면 기존 강화 효과를 덮어쓴다. 단일 원문에는 자연의 군대 다음 GCD **일월식**, 광역 원문에는 자연의 군대 직후 **화신** 분기가 별도로 적혀 있다. 이를 하나의 선형 오프너로 합치면 불가능한 버튼을 안내한다.
- **범용적 근본 원인:** 영웅·단일/광역·선택 빌드·현재 쿨다운 상태의 **배타적인 행동 경로를 빠른 요약으로 합치면서** 연속 실행할 수 없는 기술을 나열한 것. 검증 방법은 새 코드 규격/검사기 개발이 아니라 **원문의 조건부 행동을 분기형으로 요약하고, 활성 버프 상태에서 다음 GCD가 가능한지 최소 반례로 확인**하는 편집 단계다.
- **수정된 개인 비공개 HTML:** `wow_rotation_v11_balance_1215_eclipse_branch_v2_REVIEW.html` / 986,501 bytes / SHA-256 **`688f2cc56dff23f61f046553fa1d73c785d95b5f3b40cef7ec0265409d8e5402`**. 기존 개인 V11 7개 subtree 7/7 바이트 보존, 40개 규칙 ID/표 조건·이유 일치, 상태별 예제 **16개**. 숲의 수호자 단일 FoN→일월식, 광역 FoN→화신 또는 조건부 일월식, 두 영웅 모두 화신 활성 동안 일반 일월식 불가를 **첫 화면/오프너/표/예제**에 일관되게 반영. 실제 영웅 전환과 PC 1365px / 모바일 390px, 기술 팁·ESC, 기존 냉기 복귀·overflow/JS 에러 0으로 Q4 검사 PASS.
