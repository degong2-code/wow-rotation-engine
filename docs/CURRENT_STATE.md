1. **냉기 v2 / 통합 V46 내용 보완:** 같은 패치·원문에서 오프너/선택형/툴팁 누락 중 실제 행동을 바꾸는 사항 조사. V11의 유용한 매크로·기술 사전·심화 정보의 퇴보 여부 평가 후 필요한 것만 복원. 사용자 채택 UI 보존.
