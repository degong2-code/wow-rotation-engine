# ROADMAP_CHAT_FIRST — 제품 품질 실증 로드맵

> **2026-11-17 정비.** 이 문서는 **장기 완료 기준**만 유지한다. 실제 현재 순서는 [CURRENT_STATE](CURRENT_STATE.md) §4의 1~3개가 유일한 최신 운영 우선순위다. [구버전 2026-11-16 로드맵 전체](https://github.com/degong2-code/wow-rotation-engine/blob/e3416fc9643f2108187648c356d776115e5cda82/docs/ROADMAP_CHAT_FIRST.md)는 실험/진행 이력이지 다시 수행할 기본 작업 목록이 아니다.

## 1. 단기 — 통합 가능 UI와 실제 판단 정확성

- **다음 필수 검증:** 고통 V82/통합 V83의 **좋다고 평가된 시각적 구성요소**를 콘텐츠와 분리한 실제 재사용 자산으로 만들고, 냉기 독립 1종에서 화면 폭·영웅 선택·표·메뉴·툴팁을 동폭 비교. 사용자 Q3 확인 전 확정 UI 채택 금지.
- **반복 제작 시험:** 같은 UI 자산을 서로 다른 게임 메커니즘의 전문화에 적용해 **제작자 해석에 따른 편차**가 실제로 줄었는지 확인. 실패하면 기준본 지정만 추가하지 않고 자산·과정 자체를 교정.
- **판단 정합성:** 매 CREATE/UPDATE에서 원문 Gate A(선택형/hover/오프너 포함), Q0/Q1(수치·조건·예외), 상세↔첫 화면 역방향 비교. 미확정 범위는 좁게 REVIEW 종료.

## 2. 중기 — 독립 CREATE/UPDATE 재현

- WoW 전문화 **신규 CREATE 최소 2종**, 기존 V11의 **진짜 독립 제로베이스 재제작 2~3종**, 기존 전문화 **패치 UPDATE 최소 1회**를 서로 다른 원고 계보·기준 패치로 평가. 동일 초안 파생 파일을 별도 독립 성공으로 계산 금지.
- 새 집필 과정에서 기존 승인 타 전문화 DOM/JS·메뉴 보존. UI만 바꾸면 내용·기술 링크·오프너 순서의 불변을 확인.
- Q0/Q1의 실질 오류, Q2/Q3 사용자 독해 평가, Q4 PC/모바일 기능 평가를 모두 분리하고 **오류 원인이 반복해서 입증된 경우**에만 기존 도구 보완.

## 3. 장기 — 차기 패치/시즌 적응 및 V1 수용

- 새 시즌 원문 **하나만으로** 패치 변경을 분석해 전문화 CREATE/UPDATE할 수 있고, 이전 시즌 게임 조건을 자동으로 끌어오지 않아야 한다.
- 일반 ChatGPT 채팅에서 전문화명만으로 단일 HTML 제작·검증·개인 보존·최신 상태 갱신이 가능해야 한다. 독립 AI API/웹앱을 필수로 요구하지 않는다.
- 사용자에게 실제 다음 기술 선택을 제공하며 원문 누락·중대 조건 오류 0, 승인된 Q2/Q3, 기능 Q4 및 동작 환경 범위 명시. **REVIEW 제품은 전체 최종 승인본으로 집계하지 않는다.**
- 목표 달성 여부는 **실제 제품과 사용자 평가**로 판단하며 커밋·테스트·문서/검사기 수를 성과 지표로 삼지 않는다. V11 전체 전문화 전수 재제작은 출시 선결 조건이 아니다.

## 4. 원문 접근 기준 — 새 수집기 선결 금지

1. ChatGPT의 정상 공개 접근 및 선택형 페이지 확인.
2. 기존 비AI HTTP/DOM/HTML/WHML 추출 도구를 정상 허용 범위에서 재사용.
3. 사용자 제공 저장 HTML·원문 텍스트·선택형 상태.
4. 중요 원문이 없으면 해당 부분 REVIEW; 403/429 우회나 가정 보충 금지.
5. 출처 확보 완료는 단순 HTML 다운로드 성공이 아니라 **해당 분기의 실제 판단을 바꾸는 원문까지 확보한 상태**로 판정.
