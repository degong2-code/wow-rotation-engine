# ROTATION TEXTBOOK — 제품 완성 로드맵 (단기 / 중기 / 장기)

> 2026-11-16 사용자 합의의 실행 순서. **개발 진척의 단위는 교본의 판단 정확성·사용성·독립 반복 제작 성공**이며 커밋 수·검사기 수·HTML 장수는 아니다. 현재 작업/최신 버전은 [CURRENT_STATE](CURRENT_STATE.md), 프로젝트 정의는 [PROJECT_CANON](PROJECT_CANON.md).

**AI 역할 표기:** **AI 필수** = ChatGPT의 게임 의미 판단·분석·집필, **AI 보조** = 검색/기획에 유용하지만 일반 도구로 대체 가능, **비AI** = 결정론적 수집/조립/회귀 검사로 품질 유지 가능. 이 표시는 ChatGPT 대화에서의 작업 분담이며 외부 AI API를 만들라는 지시가 아니다.

## 원문 확보 — 새 시즌에도 막히지 않는 결정 트리

1. **A. ChatGPT의 정상 접근:** 대상 전문화 Wowhead 실제 페이지 URL, 패치·수정일·기준 빌드 확인 → 영웅/전투/특성/접힌 내용/hover/오프너의 **실제 반환된** 원문 확인.
2. **B. 자동 취득/추출 비AI 보조:** 기존 엔진의 HTTP/HTML/WHML/DOM 파서와 선택형 인덱스 활용. 정상 접근 가능한 HTML만 대상으로 한다. 성공 여부는 **실제 추출 원문/선택 범위**로 판정한다. 403/429 회피 금지.
3. **C. 사용자 제공 자료:** 직접 저장한 HTML/ZIP/MHTML/원문 텍스트 또는 필요한 선택 상태를 사용자가 전달. 미선택 탭/tooltip의 내용이 HTML에 들어 있는지 확인. 부족하면 어떤 자료가 필요한지 **최소한으로** 요청한다.
4. **D. 그래도 부족하면:** 확인된 범위의 검토본(REVIEW)과 정확한 미확보 범위를 전달. 불확실한 원문을 추측하지 않으며 **완전한 게임 정답 PASS로 집계하지 않는다**.
5. **수집기 신규 개발 판단:** 실제 반복되는 원문 누락 유형이 입증되고 기존 파서·브라우저·사용자 입력으로 해결할 수 없을 때만 최소 구현. 'AI는 반드시 수집해야 한다'도, '무조건 사용자 입력'도 강제하지 않는다.

## V1 완료 기준 (필수)

- **원문 Gate A:** 사용 중인 기준 패치의 영웅/전투 유형/선택형 조건/오프너/실제 관련 숨은 설명에서 중요한 내용 누락이 없어야 한다. 접근 불가가 남은 작품은 조건부 REVIEW이며 합격 표본에 넣지 않는다.
- **Q0/Q1:** 게임 상태·기술명·수치·조건·우선순위·오프너의 **중대한 판단 오류 0건**. 원문과 독립 반례 대조.
- **Q2/Q3:** 기존 V11 이상의 이해도와 첫 화면 실제 사용성, 사용자 승인. 부가 자료를 무조건 늘리지는 않지만 유용한 매크로/고급 정보 손실은 평가한다.
- **Q4:** PC/모바일, 클릭/hover, 영웅 특성·좌측 메뉴, JS 오류·넘침, 기존 본문 보존 검사 통과.
- **반복 제작 실증:** 서로 다른 **신규 CREATE 최소 2종**, **V11 제로베이스 재생성 최소 2~3종**, **기존 UPDATE 최소 1회**를 완료 기준으로 확인. 특정 전문화 하나의 성공으로 전체 범용성을 단정하지 않는다.
- **실행 UX:** 일반 ChatGPT 프로젝트 채팅에서 전문화명만으로 가능한 전체 작업을 수행하고 단일 HTML 제공. 별도 AI API/OAuth/Codespaces/독립 웹앱을 사용자에게 필수 요구하지 않는다.
- **새 패치 대응성:** Wowhead 직접·기존 비AI 추출·사용자 제공 중 **적어도 하나의 정상 원문 경로**가 확보되면 동일한 편집/검증 흐름으로 이어갈 수 있어야 한다. 실제 다음 시즌 출시 전에는 완전한 실증이라고 주장하지 않는다.

**V1 완료에 모든 전문화의 콘텐츠 완성이나 V11 7개 전체의 재생성이 필수인 것은 아니다.** 출시 후에도 전문화 추가·새 패치 UPDATE는 계속되는 운영 작업이다.
