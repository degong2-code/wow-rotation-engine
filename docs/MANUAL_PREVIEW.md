# WoW Rotation Engine — 간략 교본 프리뷰

## 제품 목표

**한국어 WoW 딜사이클 교본을 빠르게 읽고 갱신하는 것**이 이 프로젝트의 우선 목표입니다. 역사적 자료의 모든 단어를 공식 API와 일치시킬 때까지 기능 개발을 멈추지 않습니다.

현재 `content/public/`에 구조화된 7개 전문화·23개 상황별 우선순위 표·177개 기술 행·79개 심화 주제가 있으며, 이를 읽는 **사용자 중심 단일 HTML**을 생성합니다.

### 생성

```bash
python -m engine.manual_site --output dist/manual/index.html
```

GitHub Actions는 PR과 main에 push될 때 간략 교본 HTML을 생성하고, `wow-rotation-quick-reference-html` Artifact를 남깁니다. 파일을 더블 클릭해 브라우저로 열 수 있습니다. 서버·비밀 값·추가 라이브러리는 필요 없습니다.

### 화면 기능

- 전문화 7개·영웅 특성 메뉴 자동 생성 (등록된 JSON 기준)
- 단일/광역, 대상 수(1·2·3·5·8) 필터
- 검색: 기술의 한국어 이름 또는 Spell ID
- V11에서 가져온 순번과 주문 ID, 해당 ID의 Wowhead 검색 링크
- 실제 주문의 시전 조건을 **추측하지 않고** 간략판임을 명시
- Advanced Tips 79개 주제 색인, 출처 링크, 접혀 있는 기술별 출처 해시
- URL 해시 `#frost/spellslinger` 같은 형식으로 전문화/영웅 특성 공유

### 데이터 갱신

`content/public/manifest.json`의 전문화 목록과 `content/public/rules/*.json`에 자료를 추가하면 메뉴와 페이지가 자동 변경됩니다. 기존 7개 전문화 데이터는 이번 PR에서 수정하지 않았습니다. 새 전문화 추가를 위한 자동 테스트를 제공합니다.

### 확인 범위: 필요한 것만

**필수 점검:** JSON이 파싱되는지, 전문화·규칙 참조가 연결되는지, HTML이 재생성되는지, 결과물에 기술명·순서가 나타나는지.

**정보성 점검:** Blizzard API에서 조회되지 않는 효과·소모품 ID, 문장 의미의 세부 검증 상태. 이 때문에 간략판 빌드를 차단할 필요는 없습니다.

**아직 자동화하지 않는 것:** 의미가 확인되지 않은 완전한 시전 조건·전투 중 추천 판단. 존재하지 않는 문장을 AI가 채우거나 원문 전체를 무단 복제하지 않습니다.

기존의 상세 규칙 감사·로컬 WoW 애드온은 간략판 생산의 필수 단계가 아닙니다. CI에서 애드온 빌드·Artifact는 제외했습니다.

## 다음 작업 우선순위

2. 새 전문화 추가·기존 원문 변경 시 AI가 후보를 생성하는 업데이트 흐름
3. 간략판과 검토 뷰어를 분리해 공개 웹에서 빠르게 열기
