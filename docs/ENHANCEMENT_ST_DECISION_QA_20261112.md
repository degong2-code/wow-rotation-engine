## 의도적인 실패 반례와 남은 문제

- 소용돌이치는 무기 4중첩, 모든 모델링 기술을 사용 불가로 둔 상태에서 `no_rule`이 검출됨. 이 결과를 ‘게임 안에서 기술이 없다’가 아니라 **현재 QA에 모델링한 일부 우선순위가 해당 상태의 다음 행동을 결정하지 못한다**는 뜻으로 기록한다.
- 행동의 준비 여부(`*_ready`)와 영웅·대상 유형은 **판단 테스트를 구성하기 위한 입력 상태 변수**다. 스킬의 쿨다운 구조나 오프너 외 실제 중첩 취급이 전부 증명됐다는 뜻이 아니다.
- 일부 `reason`은 기본 우선순위 행에서 직접 도출한 최소 설명이다. **게임 메커니즘 및 정확한 한국어 기술명 전체 확인(Q0)**과 영웅·특성·대상 전환 전체 비교(Q1)는 별도로 진행해야 한다.
- 출처 변경·패치 갱신·순서 9행의 주문 ID 불일치 시 **검사를 중단**하며 과거 결과를 새 전문화/새 개정본에 자동 전파하지 않는다.

## 개발 회귀 검증

- 일반 공통 QA에 `action_source_marker`(해당 주문/행동을 가리키는 정확한 원문 토큰), 실제 소스 본문 SHA·인용 오프셋 확인 추가. `reason`만 임의로 작성한 경우에도 인용 원문과 행동 토큰이 존재하는지 기본 감사한다.
- **시험하지 않은 규칙**의 정의를 ‘일단 적용 가능함’에서 **그 규칙이 실제 최고 우선순위로 선택되는 상태가 존재함**으로 강화. 영원히 상위 규칙에 가려지는 하위 기술을 시험 완료로 보지 않는다.
- 실제 전문화 리뷰에 `minimum_decision_cases=6` 게이트를 명시적으로 걸었으며 13개 사례를 사용했다. 임의 전문화에 6개 숫자를 채운다고 콘텐츠 QA가 완전해지는 것은 아니다.
- 공개 CI 로그는 근거 일치 여부·규칙 수·일치 사례 수·보류 사유만 출력한다. **자동 게시 `false`**, 전체 전문화 게임 판단 검증 `false`.
