- **Chromium 실물 DOM/인터랙션:** 실제 HTML 텍스트를 headless Chromium에 삽입하는 방식으로 **1365×850 데스크톱 / 390×844 모바일** 확인. 직업·전문화 선택, 영웅 특성 전환, 각 영웅에 해당하는 우선순위 2표/물약 경로 6개 표시, 비기준 물약 경로 펼치기, 기술 툴팁 표시·Esc 닫기, 기존 화염 복귀, `#enhancement-rotation` 해시 복원, 가로 넘침 없음, JS 오류 0 — **두 화면 모두 PASS**. 실행 환경의 브라우저 정책상 로컬 `file://`/loopback 주소 직접 네비게이션이 차단되어, 테스트는 실제 HTML **`page.set_content`** 로드로 수행. 따라서 사용자의 브라우저에서 파일 열기/장기 UI 사용까지 전수 입증했다고 주장하지 않는다.

1. 이 **실물 HTML 자체**를 사용자 관점에서 검토한다. 상위 4표/12오프너 조건을 필요한 게임 증거와 대조하면서 실제 애매한 문장·누락을 교정하고, Q2/Q3 피드백을 수집한다. **새 전문화별 검사기 개발은 후순위.**

3. V3.11 원본을 raw로 읽을 수 없는 상태에서는 그 파일에 덮어쓰기한 것처럼 기록하지 않고, 별도 검토본·승인 여부를 명확히 유지한다.
