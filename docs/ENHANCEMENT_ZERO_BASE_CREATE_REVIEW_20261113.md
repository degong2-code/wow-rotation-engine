# 고양 주술사 제로베이스 CREATE — 원문부터 다시 집필, 비전/V11 시각 문법으로 출력 (2026-11-13)

## 0. 사용자 문제 제기와 재제작 범위

사용자 직접 평가: 기존 고양 V3.13 기반 V11 재배치본의 표 서식은 여전히 만족스럽지 않고, 앞서 긍정 평가를 받은 **비전 CREATE의 UI·시각 문법과도 다른 제품**처럼 보인다. **기존 고양 교본을 기초로 다시 만드는 방식은 중단하고, 실제 Wowhead 원문에서 제로베이스 재집필**한다.

이번 실제 작업은 기존 고양 `wow_rotation_v11_enhancement_reader_v313_REVIEW.html`, `wow_rotation_v11_enhancement_cross_spec_v11_REVIEW.html`, 그 섹션 HTML·메타데이터를 **콘텐츠 입력으로 열거나 사용하지 않았다**. 게임 규칙은 Wowhead 12.1.5 공개 원문에서 새로 추출했고, **표현/UI만** 이전에 사용자 긍정 평가를 받은 V11+비전 `wow_rotation_v11_arcane_canonical_projection_REVIEW.html`을 스타일 기준으로 사용했다. 기존 V11 7전문화 본문은 비공개 원본 그대로 유지.

## 1. 편집 기준과 출처 버전 경계

- **단일 기준 원문:** [Enhancement Shaman Rotation Guide — Wowhead](https://www.wowhead.com/guide/classes/shaman/enhancement/rotation-cooldowns-pve-dps), wordup, **2026-10-13 / 12.1.5**, 검색 색인에서 당일 본문 확인. 원문이 영웅별 단일·광역 각각의 순위를 제공함.

- **기준 문서에서 독립 정리:** 폭풍인도자 ST **9**, 광역 **10**; 토템술사 ST **12**, 광역 **12**. 원문에 맞춰 고정 콤보가 아닌 첫 충족 조건 기준 우선순위 사용. 오프너는 공개 인덱스의 4개 독립 경로를 재구성하되, `Liquid Luster`, `Potion of Recklessness`, `Light's Potential` 등 선택형 소모품/장신구의 배타적 실제 경로 전수는 **REVIEW**, 과거 고양에서 만든 12개 분기를 억지로 이식하지 않음.

## 4. 재현 가능한 개선 규칙

**이번에 드러난 전환점은 기술/물약 한 건이 아니라 잘못된 제작 기준점이다.** 사용자가 기존 결과가 구조적으로 불만족스럽다고 평가한 상태에서, 그 결과 파일을 변경 기준으로 삼으면 장황함·정보 역할 왜곡·탭/표 불일치를 그대로 끌고 간다. 이 경우:
1. **게임 내용은 기준 패치에 맞는 단일 원문에서 다시 도출**, 이전 전문화 HTML의 정량 규칙·선택 분기·오프너 내용을 기본값으로 재사용하지 않는다.
2. **표현은 사용자 승인 방향을 보인 다른 V11 정상군**(이번에는 Arcane 시각 계약)을 공통 역할 기준으로 재적용한다.
3. 판단 조건을 이해한 뒤 표를 설계하며, 실제 같은 규칙 객체에서 요약과 상세를 만든다. **조건은 직접 표시, 기본 판단 이유 공개, `?`는 특수 팁만**, 중요 예외는 `?` 안에만 숨기지 않는다.
4. Q0/Q1(원문/게임 판단)·Q2/Q3(설명/가독성)·Q4(HTML 기능·기존 7개 본문 보존) 별개 판정. 동일한 세부 원문이 없는 상황에는 **REVIEW**를 적용하되 교본 실물 검토 자체는 진행한다.

**현재 결론:** 고양을 제로베이스로 다시 만들고 V11/비전 UI 역할과의 정렬을 실제 파일로 구현했다. 하지만 다른 신규 전문화의 소스 전체→GAME QA 자동화를 완성했다고 주장하지 않는다. 사용자 화면 피드백 후, 길이/밀도를 조정할 때도 정량 조건을 삭제하지 않는다.
